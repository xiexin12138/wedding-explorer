## 🎯 快速开始

### 第一步：了解系统

性能监控系统包含以下组件：

```
lib/
├── performance-monitor.ts      # 核心性能监控工具
├── api-performance-wrapper.ts  # API 性能包装器
├── cache.ts                    # 增强的缓存系统
├── db-config.ts                # 数据库配置优化
└── db.ts                       # Prisma 客户端配置
```

### 第二步：为你的 API 添加监控

只需 3 行代码：

```typescript
import { withPerformanceMonitoring } from '@/lib/api-performance-wrapper';

export const GET = withPerformanceMonitoring(async (
  request: NextRequest,
  { tracker, dbMonitor }
) => {
  // 你的业务逻辑
  tracker.checkpoint('完成处理');
  return NextResponse.json({ success: true });
}, {
  name: 'API名称',
});
```

### 第三步：查看性能日志

部署后，在 Vercel Dashboard 查看日志：

```
Vercel Dashboard → 项目 → Functions → Logs
```

查找关键指标：
- 🟢 良好性能（< 500ms）
- 🟡 需要关注（500ms - 2s）
- 🔴 需要优化（> 2s）
