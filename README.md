## 地图探索功能

地图探索功能基于高德地图API实现，提供以下功能：

- 查看活动地点和周边景点
- 导航到不同景点
- 添加新的景点标记
- 查看景点详细信息
- 支持定位到当前位置

### 配置说明

使用前需要在`.env.local`文件中配置高德地图API密钥：

```
NEXT_PUBLIC_AMAP_KEY=your_amap_key_here
```

可以在[高德开放平台](https://lbs.amap.com/)申请API密钥。
